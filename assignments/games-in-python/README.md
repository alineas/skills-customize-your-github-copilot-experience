
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Construir o jogo da Forca para praticar manipulação de strings, loops, condicionais e entrada de dados do usuário em Python.

## 📝 Tarefas

### 🛠️ Implementar a Mecânica Base do Jogo

#### Descrição
Crie a estrutura principal do jogo: escolha de palavra secreta, exibição do progresso e leitura dos palpites do usuário.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória de uma lista predefinida.
- Mostrar a palavra oculta no formato com sublinhados (exemplo: `_ _ _ _`).
- Solicitar ao usuário um palpite de letra por rodada.
- Atualizar a exibição da palavra conforme os acertos.

### 🛠️ Finalizar Fluxo de Jogo e Resultado

#### Descrição
Complete as regras de vitória e derrota, controlando tentativas restantes e encerrando a partida com feedback claro ao jogador.

#### Requisitos
O programa concluído deve:

- Rastrear tentativas incorretas restantes.
- Encerrar o jogo quando a palavra for totalmente adivinhada.
- Encerrar o jogo quando as tentativas acabarem.
- Exibir mensagem final de vitória ou derrota, incluindo a palavra secreta.
